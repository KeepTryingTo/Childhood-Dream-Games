## 1. 项目概述

### 1.1 目标
实现一款俯视视角 2D 赛道竞速游戏，具备：
- 单人竞速核心玩法（与 AI 对手同场竞技）
- 真实感车辆物理：前向驱动、侧向抓地、漂移侧滑、草地减速
- 完整竞速规则：发车格、圈数计数、圈速计时、防抄近路、名次判定
- 可选扩展：氮气加速、轮胎痕迹、引擎音效、镜头跟随、最佳圈速持久化

### 1.2 技术选型（建议）

| 方案 | 技术栈 | 适用场景 |
|---|---|---|
| A（推荐） | HTML5 Canvas + JavaScript | 网页端，零安装易演示 |
| B | Python + Pygame | 桌面端，适合学习 |
| C | Unity / Godot | 商业级桌面端 |

说明：车辆物理与竞速规则写成**纯逻辑模块**（不依赖 DOM/Canvas），以固定时间步驱动，可独立运行、可单元测试；UI 仅负责渲染、镜头与输入。

## 3. 规则基线（实现依据）

### 3.1 坐标系与单位
- 世界坐标以**米**为单位，x 向右、y 向下（与 Canvas 一致）；(0,0) 为赛道包围盒中心。
- 朝向角 angle：0 = 正 +x，顺时针为正（y 向下系下 atan2(y,x) 语义）。
- 赛道默认：外包 260m × 180m，圆角半径 40m，赛道宽 16m；中心线等弧长采样 512 点。
- 速度显示：speed × 3.6 = km/h；默认极速 ≈ 55 m/s（约 198 km/h）。

### 3.2 车辆物理（每 tick，dt = 1/60 s）
1. **转向**：`angle += steer × STEER_RATE × dt × clamp(vF / V_REF, -1, 1)` —— 转向效率与车速成正比（低速打方向不位移），倒车（vF<0）时转向反向。
2. **推进**：`vF += throttle × ENGINE × dt`（草地 ×0.5，氮气 ×1.8）。
3. **制动**：`vF -= brake × BRAKE × dt`，下限 -REV_MAX（倒车极速）。
4. **阻力**：`vF -= vF × DRAG × dt`（草地阻力 ×4，等效极速骤降）。
5. **抓地**：把速度矢量按车身前向/侧向分解（vF, vS），`vS -= vS × GRIP × dt`。GRIP ≪ 阻力对 vF 的影响 → 急转时 vS 来不及衰减，产生**侧滑/漂移**。
6. **积分**：`pos += (fwd × vF + side × vS) × dt`。

### 3.3 圈数判定（防作弊关键）
- 每车维护 `totalS`（累计弧长）：`ds = wrapDelta(s_now - s_last)`（环形差，取 |ds| < 周长/2）。
- **单步上限**：`|ds| ≤ (V_MAX + ε) × dt`，超出按上限截断 —— 瞬移/抄近路无法刷进度。
- `totalS += ds` 允许负值（倒车扣进度）；`laps = floor(totalS / 周长)`，仅当 laps 增加时记圈 + 记圈速。
- 倒车过线再前进过线：totalS 先减后加回到原值，不重复记圈。

### 3.4 发车与结束
- 发车格：起点线后方按名次倒序排列，横向交错 ±0.22 × 赛道宽，朝向中心线切线。
- 玩家完成设定圈数 → `finished`，成绩定格（名次、总时间、最佳圈）；AI 可继续跑完。
- 发车倒计时（E8）：countdown 3.0s 递减，>0 时油门/转向无效，=0 解锁。

## 4. 总体设计

### 4.1 分层架构
```
┌─ UI 层：Canvas 渲染、镜头跟随、痕迹特效、音效、HUD、菜单
├─ 游戏流程层：ready/countdown/playing/paused/finished、难度、圈速统计
├─ 逻辑引擎层：RaceGame（物理 tick、圈数、碰撞、排名）+ Track（几何）
└─ 数据模型层：车辆状态矢量、赛道采样表、弧长进度
```

### 4.2 数据模型
```js
car = {
  x, y, angle,          // 位姿
  vx, vy,               // 速度矢量（侧滑即 vx,vy 与 angle 分离）
  steer, throttle, brake, nitroActive,   // 输入（AI 由 ai.js 填充）
  nitro,                // 氮气槽 0..100
  onTrack, lateral,     // 路面状态（本 tick 投影结果）
  s, totalS,            // 当前弧长 / 累计弧长（名次与圈数依据）
  lap, lapStart, lastLapMs, bestLapMs,   // 圈数与圈速
  isAI, skill, name, color, hintIdx,     // AI 元数据
  finished, finishTimeMs, rank
}
state = {
  status: 'ready' | 'countdown' | 'playing' | 'paused' | 'finished',
  cars: [car...],        // cars[0] 为玩家
  timeMs, countdown, raceLaps, winnerText
}
```

## 5. 详细实现步骤

### 步骤 0：项目初始化（0.5 天）
1. 建立目录结构，搭建 index.html、Canvas 容器与 HUD（速度/圈数/圈速/名次）。
2. 确定 UMD 模块组织（浏览器挂全局、Node 可 require）。
3. 验收：页面显示空画布与 HUD，控制台无报错。

### 步骤 1：赛道几何 track.js（1 天）
1. 圆角矩形参数化：8 段（4 直道 + 4 圆弧）按弧长拼接，等弧长采样 512 点。
2. 采样表：每点 `{x, y, s, tangent, curv}`；`pointAtS(s)` 线性插值取点。
3. `nearest(x, y)`：粗扫最近采样点 + 邻域线段投影精化，返回 `{s, lateral, onTrack}`；支持 hint 索引窗口加速。
4. 验收：第 6 节 T1、T6。

### 步骤 2：车辆物理 game.js（1.5 天）
1. `RaceGame` 构造：赛道、发车格布置、玩家 + AI 车辆初始化、状态 `ready`。
2. `tick(dt)` 按 3.2 实现物理：转向 → 推进/制动 → 阻力/抓地分解 → 积分 → 路面投影。
3. 输入口 `setPlayerInput({steer, throttle, brake, nitro})`。
4. 验收：T2 ~ T5。

### 步骤 3：圈数判定与计时（1 天）
1. totalS 累计 + 单步上限截断 + 倒车扣减。
2. 圈速：跨圈瞬间 `lapMs = timeMs - lapStart`，更新 best；达到 raceLaps → finished。
3. 排名：每 tick 按 totalS 降序刷 rank。
4. 验收：T7 ~ T9、T12。

### 步骤 4：碰撞（0.5 天）
1. 圆形碰撞体（半径 1.8m），两两检测。
2. 重叠 → 沿连线各推开一半 + 速度沿法线交换分量（弹性系数 0.4）。
3. 验收：T10。

### 步骤 5：AI 驾驶 ai.js（1 天）
1. 前瞻目标点：`pointAtS(s + clamp(6 + speed×0.55, 8, 45))`，转向 = 角误差 × 增益限幅。
2. 弯道限速：前瞻窗口取最大 |curv|，`vTarget = sqrt(GRIP_AI / curv)`，技能系数 0.88~1.06 制造差距。
3. 简易避让：正前方近距离有车 → 收油。
4. 验收：T11（AI 模拟数千 tick 持续前进不离道）。

### 步骤 6：UI 渲染 ui.js（1.5 天）
1. 静态图层：草地 + 赛道带（宽描边闭合路径）+ 红白路缘 + 边线 + 起点格纹，离屏 Canvas 缓存。
2. 车辆：旋转绘制车身/座舱/轮子，玩家高亮；氮气尾焰。
3. 镜头跟随 + 速度变焦；轮胎痕迹层（限长数组，淡出）。
4. 验收：视觉无错位，60fps 流畅。

### 步骤 7：游戏循环、输入与 HUD main.js（1 天）
1. 固定时间步累加器：`while (acc >= STEP) game.tick(1/60)`；paused 不 tick。
2. 键盘状态 → 玩家输入；空格暂停；R 重开；发车倒计时锁输入。
3. HUD：km/h 速度表、圈数 x/y、当前圈时 / 最佳圈、名次；完赛名次表覆盖层。
4. 验收：不同刷新率速度一致；暂停时计时冻结。

### 步骤 8：扩展与发布（1 天）
1. 氮气 E1、痕迹 E2、音效 E3、镜头 E4、难度/圈数 E5/E6、倒计时 E8、触屏 E7。
2. 测试补齐、README、静态托管发布。

## 8. 风险与注意事项
1. **物理与渲染帧率解耦**：严禁用 `requestAnimationFrame` 的真实 dt 驱动物理（不同刷新率速度不一致），必须固定 1/60 步长累加器。
2. **模块导出契约（v1.1 实际踩坑）**：逻辑模块在 Node 端 `require` 与浏览器端全局挂载的结构不同（命名空间 vs 直接构造器），入口引用方式不一致会在**页面加载即崩溃且不报错到 UI**。必须以冒烟测试 S1 固化契约，任何模块导出结构调整都要同步校验。
3. **抄近路刷圈**：弧长累计必须带单步上限；否则车辆横向穿越内场可瞬间"跑完一圈"。测试 T8 必须覆盖。
4. **漂移参数手感**：GRIP 过大无漂移、过小像冰面；建议 vS 半衰期 ≈ 0.15–0.3s，以 60Hz 换算每 tick 衰减系数。注意速度合成必须使用**分解时刻的基向量**，否则转向会连带旋转速度矢量、侧滑被完全消除（v1.0 实际踩坑）。
5. **完赛车辆行为**：完赛后若持续满刹会刹成倒车、掉头乱跑并回退圈数 —— 完赛车应停油轻刹滑停（vF ≤ 0.5 后不再加刹）。
6. **AI 卡墙**：前瞻距离随速度自适应、弯道限速必须基于**前方窗口最大曲率**而非当前点；仍需冒烟测试防退化。
7. **碰撞穿透**：高速对穿时单次分离不足 → 分离量按重叠深度 + 沿法线速度交换，必要时同帧二次迭代。
8. **镜头抖动**：前瞻偏移必须对速度矢量做低通平滑，避免漂移时镜头高频抖动。
9. **倒车转向反向**：vF < 0 时转向力矩符号翻转（真实车辆行为），UI 提示玩家避免困惑。
10. **起步碰撞**：发车格交错布车 + AI 巡线归中可能起步硬挤 —— AI 避让横向阈值必须大于碰撞直径（3.6m）。

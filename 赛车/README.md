# 极限竞速（Racing）

依据《require.md 需求与实现步骤文档 v1.1》完整实现的俯视视角 2D 赛道竞速网页游戏，覆盖全部 P0 核心功能与 P1 扩展功能（触屏控制除外全部实现）。

## 运行方式

**方式一（零依赖，推荐）**：直接双击 `index.html` 用现代浏览器打开即可游玩（打开后自动 3 秒倒计时发车）。

**方式二（本地静态服务）**：

```bash
python -m http.server 8080
```

访问 `http://localhost:8080`。

**演示模式**（AI 代驾观战）：在地址后加 `?demo`，如 `http://localhost:8080/?demo`。

**运行测试（Node.js ≥ 14）**：

```bash
node tests/game.test.js       # T1~T14 逻辑单元测试 + 倒计时/漂移/氮气扩展用例
node tests/browser-smoke.js   # S1~S5 浏览器端冒烟（mock DOM/Canvas 端到端完赛）
```

## 操作说明

| 按键 | 功能 |
|---|---|
| ↑ / W | 油门 |
| ↓ / S | 刹车 / 长按倒车 |
| ← → / A D | 转向 |
| Shift | 氮气加速（槽满 100，随时间恢复） |
| 空格 | 暂停 / 继续 |
| R | 重新开始 |
| 触屏 | 虚拟按键（自动出现在触屏设备） |

## 玩法要点

- **发车**：3-2-1 红灯倒计时，GO 之前油门无效
- **漂移**：高速入弯打方向产生侧滑，后轮留下轮胎痕迹；漂移过弯比硬刹更快
- **惩罚**：离开赛道（草地）阻力 ×3.5、动力减半，自然减速
- **策略**：氮气留给出弯后的长直道；弯道前提前刹车，入弯带漂移
- **目标**：与 3~5 名 AI 同场竞技，跑完 1/3/5 圈，冲击最佳圈速纪录

## 功能清单

### P0 核心功能（全部完成）

| 编号 | 功能 | 实现 |
|---|---|---|
| F1 | 赛道生成 | 圆角矩形闭合赛道 260×180m，圆角 40m，等弧长采样 512 点 |
| F2 | 几何查询 | 粗扫 + 邻域线段投影精化，返回弧长 / 横向偏移 / 在道判定（hint 窗口加速） |
| F3 | 车辆物理 | 速度矢量前向/侧向分解：推进 / 制动 / 阻力 / 抓地，固定 60Hz |
| F4 | 漂移模型 | 侧向抓地衰减（半衰期 ≈0.17s）低于前向 → 急转自然侧滑，倒车转向反向 |
| F5 | 路面判定 | \|lateral\| > 半宽 → 草地：阻力 ×3.5、动力 ×0.5、抓地 ×0.55 |
| F6 | 输入控制 | ↑↓←→ / WASD |
| F7 | 固定时间步 | 累加器驱动 1/60s 物理 tick，rAF 仅渲染，刷新率无关 |
| F8 | 圈数判定 | totalS 累计 + 单步上限截断（防瞬移刷圈），倒车扣减不重复记圈 |
| F9 | 圈速计时 | 每圈用时 / 上一圈 / 最佳圈；完成赛制圈数即完赛 |
| F10 | 车车碰撞 | 圆形碰撞体分离 + 法向冲量交换（弹性 0.4），带撞击音效与火花圈 |
| F11 | AI 对手 | 前瞻点追踪 + 弯道曲率限速 + 技能差异（0.88~1.06）+ 简易避让 |
| F12 | 名次判定 | 按 totalS 实时排名，完赛者按完赛时间优先定格 |
| F13 | 暂停 / 重开 | 空格 / 按钮 / R 键；失焦自动暂停 |
| F14 | 最佳圈速持久化 | localStorage 按 赛道+圈数档 记录，破纪录才写入 |

### P1 扩展功能

- **E1 氮气**：Shift 释放（动力 ×1.8、极速 ×1.25），槽量 100、消耗 33/s、恢复 4.5/s
- **E2 轮胎痕迹**：侧滑 >6.5 m/s 落双轮痕迹，限长 900 点、随时间淡出
- **E3 音效**：Web Audio 合成引擎声（随速度变调）、碰撞、氮气、过圈提示、完赛旋律
- **E4 镜头跟随**：速度方向前瞻 + 变焦（速度越快视野越广），指数平滑防抖
- **E5 难度**：新手 3 AI / 标准 4 AI / 大师 5 AI
- **E6 赛制**：1 圈冲刺 / 3 圈 / 5 圈耐力
- **E7 触屏控制**：虚拟按键（触屏设备自动显示）
- **E8 发车倒计时**：3s 红灯序列，锁输入防抢跑
- **E9 演示模式**：`?demo` 或 `window.RACE_DEMO`，AI 代驾玩家观战/验证

## 架构（逻辑与 UI 严格分离）

```
┌─ ui.js         Canvas 渲染 / 镜头 / 痕迹 / 小地图 / 音效（浏览器专用）
├─ main.js       固定时间步循环 / 输入 / HUD / 菜单 / 演示模式（浏览器专用）
├─ game.js       RaceGame 纯逻辑引擎：物理/圈数/碰撞/排名 ┐
├─ track.js      赛道几何：生成/投影/弧长表              ├─ Node 可 require，可单测
├─ ai.js         前瞻追踪 + 弯道限速驾驶（纯逻辑）        │
└─ storage.js    最佳圈速持久化（localStorage/内存降级）   ┘
```

- 纯逻辑模块采用 UMD 导出，浏览器挂全局、Node 直接 `require`，零 DOM 依赖；
  浏览器端导出为命名空间对象（`window.RaceGame = {RaceGame, PHYS, clamp}`），该契约由冒烟测试 S1 固化
- 车辆物理按"分解 → 转向 → 推进/制动 → 阻力/抓地 → 用分解基合成"顺序执行，
  车身朝向与速度矢量自然分离，形成真实漂移手感
- 圈数计数基于弧长累计的单步上限（极速 × dt），任何瞬移/抄近路都无法刷进度

## 已知限制

- 赛道为单一固定布局（圆角矩形），未提供多赛道选择
- AI 避让为简化模型（收油 + 轻微外偏），极限贴身对抗下仍可能发生碰撞
- 漂移无手刹辅助（无单独手刹键），完全依赖转向 + 速度的物理侧滑
- 音效为 Web Audio 合成，无引擎声多缸调制，听觉拟真有限

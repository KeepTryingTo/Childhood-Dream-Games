# 中国象棋（Xiangqi）

依据《require.md 需求与实现步骤文档 v1.0》完整实现的网页版中国象棋，覆盖全部 P0 核心功能与 P1 扩展功能（联机除外）。

## 运行方式

**方式一（零依赖，推荐）**：直接双击 `index.html` 用现代浏览器打开即可游玩（普通 script 加载，无需服务器）。

**方式二（本地静态服务）**：

```bash
# 任选其一
python -m http.server 8080
npx serve .
```

访问 `http://localhost:8080`。

**运行单元测试（Node.js ≥ 14）**：

```bash
node tests/rules.test.js
```

### P1 扩展功能

- **E1 AI 对战**：简单 / 中等 / 困难三档；Negamax + α-β 剪枝 + MVV-LVA 排序 + 迭代加深 + 静态搜索，单步 ≤ 3 秒（实测 hard 档开局约 150ms）
- **E2 存档读档**：localStorage 持久化，刷新后可恢复完整对局（含模式与难度）
- **E3 走子记录**：标准中文记谱（炮二平五、马8进7、前/后消歧），滚动列表展示
- **E4 走子动画**：200ms easeOutCubic 平滑移动
- **E5 音效**：WebAudio 合成落子/吃子/将军/胜利音，无外部音频文件，可开关
- E6 联机对战：按文档建议列为二期，未实现

## 架构（逻辑与 UI 严格分离）

```
┌─ ui.js        Canvas 渲染 / 交互 / 动画 / 音效（浏览器专用）
├─ main.js      控制器：模式、按钮、AI 调度（浏览器专用）
├─ game.js      对局流程：回合、悔棋、存档、中文记谱   ┐
├─ rules.js     规则引擎：走法/将军/胜负（纯逻辑）      ├─ Node 可直接 require，可单测
├─ ai.js        评估 + α-β 搜索（纯逻辑）              ┘
└─ model.js     数据模型：棋子编码、初始布局、工具函数   ┘
```

- `model.js / rules.js / game.js / ai.js` 采用 UMD 导出，浏览器挂 `window.XQ*`，Node 直接 `require`，**零 DOM 依赖**
- 棋子编码：`0=空`，红正黑负，`1将 2士 3象 4马 5车 6炮 7兵`
- 坐标：`(row, col)`，row 0 为黑方底线（棋盘顶部），row 9 为红方底线

## AI 说明

- 评估：子力值（车900/炮450/马400/象200/士200/兵100，过河兵200）+ 位置价值表（PST，兵/马/车/炮）
- 搜索：Negamax + α-β；根节点完整合法性过滤保证 AI 永不出非法着法；MVV-LVA 吃子排序；迭代加深（时限 2.5s 硬截断）；静态搜索（qsearch 深度 8）缓解水平线效应
- 难度：简单 = 深度1 + 评分随机扰动；中等 = 深度3；困难 = 深度4（超时自动降层，保证 ≤3 秒出招）

## 已知限制

- 困毙/将死外的和棋规则（如长将判负、自然限着 60 回合无吃子判和）暂未实现
- AI 在 Web Worker 中运行（文档可选项）暂未启用；hard 档实测远低于 3 秒，不阻塞感知
- 联机对战为二期目标

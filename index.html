🏡 溪畔村庄 · 需要本地服务器运行

这款游戏使用 ES Module 构建，直接以文件方式（file://）打开会被浏览器安全策略拦截，无法加载。任选下面一种方式即可开玩：

方式一 · 静态服务（推荐，无需安装依赖）
cd "D:\conda3\Transfer_Learning\my games\finished"
python -m http.server 8080
然后访问 http://localhost:8080/荒野求生/dist/index.html
方式二 · 开发模式（进入游戏目录）
cd "D:\conda3\Transfer_Learning\my games\finished\荒野求生"
npm install
npm run dev
然后访问 http://localhost:5200
仍要尝试打开 →

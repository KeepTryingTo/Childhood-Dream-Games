# 贪吃蛇（Snake）

依据《require.md 需求与实现步骤文档 v1.0》完整实现的网页版贪吃蛇，覆盖全部 P0 核心功能、P1 扩展功能（双人对战除外全部实现），并包含 AI 自动寻路。

## 运行方式

**方式一（零依赖，推荐）**：直接双击 `index.html` 用现代浏览器打开即可游玩。

**方式二（本地静态服务）**：

```bash
python -m http.server 8080
```

访问 `http://localhost:8080`。

**运行测试（Node.js ≥ 14）**：

```bash
node tests/game.test.js   # T1~T12 单元测试 + 扩展用例
node tests/e2e.js         # AI 端到端冒烟
```

## 操作说明

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 改变方向（双人：WASD=绿方，方向键=蓝方） |
| 空格 | 暂停 / 继续 |
| R | 重新开始 |
| 手机滑动画布 | 控制方向（单人） |

## 功能清单

### P0 核心功能（全部完成）

| 编号 | 功能 | 实现 |
|---|---|---|
| F1 | 网格棋盘 | 20×20 默认，格宽随难度自适应 |
| F2 | 蛇体表示 | 有序坐标队列，头在队首，初始长度 3 |
| F3 | 移动逻辑 | 每 tick 按当前方向前进一格 |
| F4 | 输入控制 | 方向键 / WASD |
| F5 | 食物生成 | 收集空格随机选点，绝不与蛇身/障碍重叠 |
| F6 | 吃食物 | 蛇长 +1、分 +10、刷新食物 |
| F7 | 碰撞判定 | 撞墙 / 撞自身 → 游戏结束（含尾节陷阱处理） |
| F8 | 游戏循环 | 固定时间步累加器驱动 tick，rAF 仅负责渲染 |
| F9 | 计分与最高分 | 实时 HUD；最高分按难度持久化 localStorage |
| F10 | 暂停 / 重开 | 空格暂停；R 键 / 按钮重开 |

### P1 扩展功能

- **E1 穿墙模式**：出界从对侧绕回，勾选即用
- **E2 难度选择**：简单 150ms/20×20、中等 100ms/25×25、困难 70ms/30×30
- **E3 障碍物**：随机 12 块墙（自动避开蛇初始区域），穿墙模式下障碍仍致死
- **E4 动态加速**：每吃 5 个食物 `speedMs ×0.92`，下限 60ms
- **E5 特殊食物**：每吃 5 个概率刷新，限时 50 tick 闪烁提醒——
  `分`+50 分 ｜ `慢`速度 ×1.25（上限 250ms） ｜ `缩`蛇身 -2 节 +20 分
- **E6 音效动画**：WebAudio 合成音效（吃/特殊/死亡/通关）；两逻辑帧间蛇身线性插值平滑移动
- **E7 双人对战**：两条蛇（绿 WASD / 蓝方向键），撞对方身体致死，头对头判平局，存活者胜
- **E8 AI 寻路**：BFS 追食物 + 追尾可达性安全检查 + flood fill 防困死（支持穿墙/障碍）

### 满盘处理

蛇占满全棋盘时判**通关胜利**（`win=true`），不会进入随机找空格死循环。

## 架构（逻辑与 UI 严格分离）

```
┌─ ui.js         Canvas 渲染 / 插值动画 / 音效（浏览器专用）
├─ main.js       固定时间步循环 / 输入 / HUD / 菜单（浏览器专用）
├─ game.js       SnakeGame 纯逻辑引擎：移动/吃食/碰撞/状态机 ┐
├─ ai.js         BFS + 安全性检查寻路（纯逻辑）                ├─ Node 可 require，可单测
└─ storage.js    最高分持久化（localStorage/内存降级）          ┘
```

- `game.js / ai.js / storage.js` 采用 UMD 导出，浏览器挂全局、Node 直接 `require`，**零 DOM 依赖**
- 方向缓冲：`dirQueue` 最多缓存 2 个方向，每 tick 应用一个，杜绝一帧连按导致的 180° 自杀

## AI 端到端表现（tests/e2e.js 实测）

| 场景 | 存活 tick | 得分 | 蛇长 |
|---|---|---|---|
| 基础 20×20 | 1703 | 990 | 98 节 |
| 穿墙 20×20 | 1758 | 1360 | 131 节 |
| 障碍+穿墙+加速 25×25 | 2421 | 1500 | 153 节 |
| 困难档 30×30 | 5000+（未死） | 1790 | 177 节 |

稳健性 5/5 局达到 15+ 食物；AI 死亡均发生在蛇身极长（60+ 节）之后，符合贪吃蛇后期固有难度。

## 已知限制

- 双人模式无独立食物/道具系统，共享一个食物
- AI 在蛇极长时会因安全空间缩小而逐渐被困死（非 Hamilton 回路策略），符合"朴素 BFS + 安全检查"的文档定位
- 最高分仅记录单人模式；双人模式以实时比分展示

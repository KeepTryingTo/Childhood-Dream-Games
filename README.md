## 运行方式

- **俄罗斯方块 / 贪吃蛇 / 五子棋 / 中国象棋 / 音乐播放器 / 赛车（极限竞速） / 炒菜（疯狂后厨）**：直接用浏览器打开对应目录下的 `index.html` 即可（均零依赖，双击即用）。
- **荒野求生（溪畔村庄）/ 机战**：基于 Vite 构建（目录内含 `dist/` 生产构建产物），以 `file://` 方式直接打开会被浏览器拦截，需任选其一：
  - **静态服务（推荐）**：在本目录执行 `python -m http.server 8080`，然后访问 `http://localhost:8080/荒野求生/dist/index.html` 或 `http://localhost:8080/机战/dist/index.html`
  - **开发模式**：进入对应目录执行 `npm install` 后运行 `npm run dev`（荒野求生 → http://localhost:5200，机战 → http://localhost:5180）

各游戏的详细玩法说明、操作方式与实现细节，请参阅对应游戏目录内的 `README.md` 与 `require.md`。

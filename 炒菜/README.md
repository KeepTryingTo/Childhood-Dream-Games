# 疯狂后厨（Crazy Kitchen）· 全自动模拟

依据《require.md v3.1》实现的**全自动协作模拟**：餐厅 + 厨房场景中，切菜师、主厨、跑堂、经理四名小人自动分工协作，顾客进店**坐在椅子上**点单，菜做好由跑堂经**传菜口**送到桌上——全程自动，无需操作。v3.1 修复场景合理性：座位系统、双门通道、碰撞避障。

## 运行方式

**方式一（零依赖，推荐）**：直接双击 `index.html`，1.5 秒后首位顾客自动进门（首次打开有 5 步新手引导）。

**方式二（本地静态服务）**：`python -m http.server 8080`

**运行测试（Node.js ≥ 14）**：

```bash
node tests/game.test.js       # U1~U12 + V1~V6 + W1~W4 引擎与场景规则单测
node tests/browser-smoke.js   # S1~S6 浏览器端冒烟
```

## 观赏控制（非游戏操作）

空格暂停 · **1/2/3 或按钮调速 1×/2×/4×** · R 重开 · 🌙 打烊结算

## 核心场景（全自动 FSM）

```
🚪门 ──顾客──→ 🪑 4 桌×4 椅（坐椅点单·气泡+耐心环）      🎨 4 套装修主题
                        ↑ 跑堂经「传菜口」送菜 ↓ 留脏盘    🎡 四季轮换 + 节日横幅
🧱 隔断墙 · 两扇门（北=传菜口 / 南=员工通道）              🐭💧🔥 动态事件
🔔 取餐台 ← 主厨装盘 ← 🍳 灶台 ← 备菜台 ← 🔪 砧板 ← 🧊 冰箱  👔 经理现场处置
                        🚰 水槽（脏盘洗净回栈）
```

| 角色 | 自动行为 |
|---|---|
| 🔪 配菜师 | 按订单补缺：冰箱取料（走侧走廊绕行）→ 砧板切配 → 送备菜台 |
| 🍳 主厨 | 取料下锅 → 翻炒加速 → **卡火候完美窗口出锅** → 装盘 → 取餐台 |
| 🏃 跑堂 | 上菜优先（经传菜口送到桌旁服务位），空闲收脏盘送洗 |
| 👔 经理 | 巡逻催促（💢加速）+ **处置事件**：驱鼠 / 修漏水 / 灭灶火 |

**v3.1 空间规则**：实体不可穿墙、不可穿台面/餐桌（圆-AABB 推离滑移）；跨区必走两扇门（三段路点导航）；卡死自动侧向逃逸；顾客坐在椅子上而非桌心。

**动态事件**（开局 50s 后随机）：🐭 老鼠潜入偷备菜（经理驱赶）；💧 地板漏水（区域内减速，经理修理，采样避开台面）；🔥 灶台起火（主厨避让，经理扑灭）。

## 长线系统

- **🎨 装修主题**：暖木小馆 / 青花雅苑 / 夜市霓虹 / 马卡龙屋（地砖、隔断、桌布联动，自动保存）
- **🎡 季节**：春夏秋冬每 3 分钟轮换（地板色调 + 花瓣/落叶/雪花粒子），可手动切换；节日彩蛋（元旦/劳动节/国庆/圣诞横幅）
- **🏅 成就 ×13**：单局（完美主义/财源广进/满堂彩）+ 累计（百炼成厨/灭鼠英雄/消防队员/全菜谱大师/四季餐馆…），达成 toast + 琶音
- **📖 图鉴**：菜品 ×3 + 顾客 ×3，出品/接待计数点亮
- **🏆 荣誉榜**：打烊结算记录 top10（昵称/营业额/上菜/日期），本地持久化
- **新手引导**：首次 5 步引导条（可跳过/可重看）；数字弹跳、toast 滑入等 UI 动效

> 说明：本项目为零依赖纯前端网页，"异步好友互助"落地为**本地荣誉榜 + 跨局累计成就**（无后端，不伪造联网功能）。

## 架构（逻辑与 UI 严格分离）

```
┌─ ui.js            小人渲染 / 门·椅·主题·季节·事件特效 / Web Audio 音效（浏览器专用）
├─ main.js          循环×速度 / HUD 动效 / tabs 面板 / 打烊结算 / 引导（浏览器专用）
├─ game.js          KitchenSim 纯逻辑：FSM / 门导航 / 碰撞推离 / 环境事件 / 季节 ┐
├─ achievements.js  成就检查 / 历史合并 / 图鉴视图（纯逻辑）                      ├─ Node 可 require
├─ data.js          食材/菜谱/点位/墙体·门·座位/主题/季节/节日/事件配置          │
└─ storage.js       多 key 持久化（榜单/历史/装扮/昵称/引导）                    ┘
```

## 已知限制

- 角色间（人-人）不互相碰撞，允许重叠穿行（俯视卡通风格可接受）
- 碰撞滑移在极端贴边场景依赖卡死逃逸兜底（1.2s 延迟）——观测未触发
- 单炒锅单砧板；高峰期主厨/配菜师是吞吐瓶颈
- 荣誉榜为本地存储，换浏览器/清缓存不保留
- v1.0 玩家操作模式已被替换（历史设计见 require.md 第 9 章）

# 俄罗斯方块（Tetris）

依据《require.md 需求与实现步骤文档 v1.0》实现的网页版俄罗斯方块——零依赖、双击即用，采用**标准 SRS 踢墙**与 **7-bag 随机器**的现代规则实现。

## 运行方式

**直接双击 `index.html`** 用 Chrome / Edge / Firefox / Safari 打开即可。

运行单元测试（Node ≥ 14）：

```bash
node tests/rules.test.js
```

## 操作说明

| 键位 | 功能 |
|---|---|
| ← / A | 左移 |
| → / D | 右移 |
| ↑ / W / X | 顺时针旋转（SRS 踢墙） |
| Z | 逆时针旋转 |
| ↓ / S（可按住） | 软降（每格 1×等级分） |
| 空格 | 硬降（瞬间落底，每格 2×等级分） |
| C | Hold 暂存/换回（每轮锁定一次） |
| P | 暂停 / 继续 |
| R / Enter | 重开 / 开始 |

移动端：显示触摸按钮（◀ ▶ ⟳ ▼ ⤓ HOLD，长按连续移动）。

## 功能清单

### P0 核心功能（全部完成）

| 编号 | 功能 | 实现 |
|---|---|---|
| F1 | 10×20 网格 | Canvas 固定格宽渲染，高分屏适配 |
| F2 | 七种方块 | I/O/T/S/Z/J/L，标准 SRS 矩阵与配色 |
| F3 | 7-bag 生成 | Fisher–Yates 打乱，每 7 块各出现一次，杜绝"不出某块" |
| F4 | 移动/软降/硬降 | 软降逐格 1×等级分；硬降瞬间落底每格 2×等级分（NES 语义） |
| F5 | 旋转踢墙 | **完整标准 SRS 踢墙表**（JLSTZ 与 I 各一套，8 组迁移 × 5 个偏移） |
| F6 | 锁定与堆叠 | 触底/碰撞锁定写入网格 |
| F7 | 消行判定 | 满行检测 → 移除 → 上方整体下移（含中间空行场景单测） |
| F8 | 碰撞检测 | 边界 + 锁定块；顶部隐藏区（row<0）支持旋转上踢 |
| F9 | 游戏结束 | 新方块生成即碰撞 → over（符合风险 5 的正确判定） |
| F10 | 计分与等级 | 单行 100/双行 300/三行 500/四行 800 × 等级；每 10 行升级；间隔 max(100, 800−(N−1)×50) |
| F11 | 暂停/重开 | P 暂停（逻辑冻结）、R/Enter 重开 |
| F12 | 预览 | NEXT 3 个 + HOLD 面板 |

### P1 扩展功能

- **E1 幽灵方块**：半透明硬降投影
- **E2 Hold**：C 键暂存/换回，每轮锁定仅一次
- **E3 音效**：Web Audio 合成（移动/旋转/锁定/消行/Tetris/升级/结束），可开关
- **E4 动画**：消行白闪两阶段锁定（逻辑挂起 clearingRows → 倒计时后真正消行），闪烁期间下落暂停
- **E5 持久化**：localStorage 最高分（带写入探测与内存降级）
- **E6 键盘**：全键位支持，旋转/Hold/硬降忽略按键自动重复（防误触连发）
- **E7 响应式**：移动端竖排布局 + 触摸按钮
- E8 双人模式：二期目标（按文档建议）

## 架构（逻辑与 UI 严格分离）

```
UI 层          ui.js（Canvas 渲染）/ index.html / style.css
输入层         input.js（键盘 + 触摸）
流程层         main.js（固定时间步循环 / HUD / 音效 / 状态弹层）
逻辑引擎层      game.js（TetrisGame：生成/移动/旋转/锁定/消行/计分/Hold/幽灵）
规则层         rules.js（isValid / SRS 踢墙表 / 消行 / 计分表 / 等级速度）
数据模型层      model.js（形状矩阵 / 颜色 / 旋转 / 7-bag）
```

- `model.js / rules.js / game.js / storage.js` 为 UMD 模块：浏览器挂 `window.Tetris*`，Node 直接 `require`，**零 DOM 依赖可单测**
- 渲染用 `requestAnimationFrame` 独立进行；逻辑下落由累计时间步驱动（切后台回来步长限制 200ms 防跳变）

## 测试（tests/rules.test.js，20 项全部通过）

覆盖 require.md 第 6 节全部用例：

- T1/T15：7-bag 每组恰好一次、队列空无缝补充（30 块分布均匀）
- T2：左右移动越界与重叠拦截
- T3/T4：软降计分、硬降落底与每格计分
- T5/T6：旋转合法性、密闭空间拒绝、**SRS 踢墙两个真实场景**（T 块贴地上踢、I 块竖井水平 +2 踢）
- T7：锁定与已锁定块碰撞的正确写入
- T8/T8b：消行下移（含中间空行）、单行计分
- T9：Tetris 四行 800×等级
- T10：生成即碰撞 → 结束
- T11：每 10 行升级、速度公式
- T12/T13：暂停状态冻结、重开复位
- T14：Hold 每轮一次、暂存换回
- E1：幽灵方块落点；E4：两阶段消行动画推进

> 测试曾暴露一个真实缺陷：rules 旋转函数使用 `piece.position.row`（文档 4.2 嵌套格式）而引擎 current 为扁平 `{row, col}`，接口不一致导致旋转必然报错——已统一为扁平接口并回归通过。

## 已知限制

- 无锁定延迟（lock delay）：方块触底即锁定，与经典 NES 行为一致
- E8 双人模式按文档建议列为二期
- 暂无 T-Spin 特殊计分

# 五子棋 · Gomoku

一个基于 **HTML5 Canvas + 原生 JavaScript** 实现的五子棋游戏，遵循 `require.md` 需求文档开发。

## ✨ 功能特性

### 核心功能（P0）
| 功能 | 说明 |
|---|---|
| 棋盘绘制 | 15×15 交叉点、星位（天元+四星）、坐标标签（列 A-O，行 1-15） |
| 棋子绘制 | 径向渐变 + 阴影的黑白棋子，落于交叉点 |
| 落子交互 | 点击空交叉点落子，黑先白后交替 |
| 胜负判定 | 横/竖/两斜任意方向连五即胜；满盘判和 |
| 终局处理 | 状态提示、锁定棋盘、高亮连五连线 |
| 重新开局 | 随时重开 |
| 悔棋 | 双人模式回退 1 手；人机模式回退 2 手 |

### 扩展功能（P1）
| 功能 | 说明 |
|---|---|
| AI 对战 | 简单 / 中等 / 困难三档（Negamax + α-β 剪枝） |
| 规则切换 | 自由规则 ↔ Renju 规则（黑方禁手：三三、双四、长连） |
| 存档读档 | localStorage 保存局面 |
| 走子记录 | 列表展示，如 `#12 黑 H8` |
| 标记 | 最后一手红点、悬停虚影 |

## 🚀 运行方式

**方式一（推荐）**：直接双击 `index.html` 用浏览器打开即可（无需服务器，兼容 `file://`）。

**方式二**：本地起一个静态服务器：

```bash
# 任选其一
python -m http.server 8080
# 或
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

## 🎮 玩法说明

1. 选择**模式**：双人对战 / 人机对战（人机模式下人类执黑先手，AI 执白）。
2. 选择**难度**：简单（深度 1+随机）、中等（深度 2）、困难（深度 4）。
3. 选择**规则**：
   - **自由规则**：任意方向连五（含长连 ≥6）即胜。
   - **Renju 规则**：黑方禁手（三三、双四、长连），禁手点禁止落子；成五优先；白方连五（含长连）为胜。
4. 点击棋盘交叉点落子；可用「悔棋」「存档」「读档」「重新开局」按钮。

## 🧠 实现说明

- **分层架构**：`model`（数据）→ `rules`（规则引擎，纯逻辑可单测）→ `ai`（搜索）→ `game`（对局流程）→ `ui`（渲染）。
- **AI 算法**：
  - 候选点：仅取已有子切比雪夫距离 ≤2 的空点。
  - 评分表：连五 10,000,000 / 活四 1,000,000 / 冲四 100,000 / 活三 10,000 / 眠三 1,000 / 活二 100 / 眠二 10。
  - 综合分 = 己方进攻分 + 对方防守分 × 0.9。
  - 杀棋快通道：一步成五直接落；对方一步成五必堵。
  - 搜索：Negamax + α-β 剪枝 + 着法排序（Top N 扩展）。
- **Renju 禁手**：采用线串提取 + 模式匹配（长连 run 判定、四数统计、活三棋形统计），活三/冲四为模式表近似实现（详见 `rules.js` 注释）。

## ⚠️ 已知说明

- Renju 禁手的"活三/冲四"严格定义具有递归性，本实现采用模式表近似（满足常规对局），已注明边界。
- AI 困难档单步思考时间经测试 ≤3 秒（满足需求）。

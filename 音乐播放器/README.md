# 云音 · 网页音乐播放器

依据《require.md 需求与实现步骤文档 v1.0》实现的纯前端音乐播放器——零依赖、无需后端、双击即用。

## 运行方式

**直接双击 `index.html`** 用 Chrome / Edge / Firefox / Safari 打开即可（普通 script 加载，无模块 CORS 限制）。

> 可选：`python -m http.server 8080` 后访问 `http://localhost:8080`（效果相同）。

运行单元测试（Node ≥ 14）：

```bash
node tests/lrc.test.js
```

## 功能清单

### P0 核心功能（全部完成）

| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 文件导入 | 按钮多选 / 全页拖拽；mp3/flac/m4a/ogg/wav 等；文件名自动解析"艺术家 - 标题" |
| F2 | 播放/暂停 | 图标随状态切换，唱片旋转动画联动 |
| F3 | 上/下一首 | 手动切歌；播放中续播、暂停中保持暂停（T5） |
| F4 | 进度控制 | rAF 驱动（非 4Hz timeupdate）；点击/拖拽 seek，拖拽中不抖动（T3） |
| F5 | 音量控制 | 滑块 + 静音（记忆静音前音量） |
| F6 | 播放模式 | 顺序 / 列表循环 / 单曲循环 / 随机（Fisher–Yates 洗牌，一轮不重不漏） |
| F7 | 播放列表 | 点击切歌、当前项高亮 + 跳动动效、删除单曲、清空、搜索过滤 |
| F8 | 歌曲信息 | 标题/艺术家；缺省旋转唱片动画（播放时旋转、暂停时停止） |
| F9 | 自动续播 | 一首结束按当前模式自动切下一首；order 末首停止 |
| F10 | 错误处理 | 解码失败/格式不支持：toast 提示 + 自动跳过；全曲失败自动停止 |

### P1 扩展功能（E1~E8 全部完成）

- **E1 LRC 歌词**：解析 `[mm:ss.xx]` / 多时间标签 / `[offset:]`；rAF + 二分查找逐行高亮，transform 平滑居中滚动；支持拖入同名 `.lrc` 自动关联
- **E2 频谱可视化**：Web Audio AnalyserNode（fftSize 512），对数分组的 48 柱渐变频谱；`createMediaElementSource` 单例保护；API 不可用时自动降级装饰动画
- **E3 键盘快捷键**：空格播放/暂停、←/→ ±5s、↑/↓ 音量、N/P 切歌；输入框聚焦时自动失效（T10）
- **E4 Media Session**：系统媒体键/锁屏控制与标题/艺术家元数据
- **E5 持久化**：localStorage 记忆音量/模式/主题；**IndexedDB 持久化本地音频 Blob**，刷新后自动恢复上次会话列表（objectURL 重建）
- **E6 搜索过滤**：按标题/艺术家实时过滤（视图过滤，不影响数据索引）
- **E7 主题切换**：深色（默认）/ 浅色，刷新后保持
- **E8 响应式**：桌面双栏 → 移动端单列自适应

## 架构（逻辑与 UI 严格分离）

```
UI 层          ui.js / visualizer.js / index.html / style.css
应用流程层      main.js（导入 / 持久化 / Media Session / IndexedDB 恢复）
服务层         lrc.js / storage.js / model.js(EventBus)
播放核心层      player.js（PlayerCore：Audio 封装 + 模式 + 切歌）
数据模型层      model.js（Track / formatTime / EventBus） + playlist.js（Playlist）
```

- `model.js / lrc.js / playlist.js / storage.js` 为 UMD 模块：浏览器挂 `window.MP*`，Node 直接 `require`，**零 DOM 依赖可单测**
- `PlayerCore` 不触碰任何 DOM，通过 EventBus 通知 UI

## 测试（tests/lrc.test.js，18 项全部通过）

覆盖 require.md 第 6 节关键逻辑：

- LRC 解析：标准/多标签/三位毫秒/offset 正负/元数据忽略/升序（T9）
- 二分定位：首行前、行间边界、超尾、空歌词（T9）
- 四种模式索引：order 末首停止 / list-loop 回首 / single 播完重播·手动切换 / shuffle 一轮不重不漏（T2）
- 列表索引维护：删除当前曲（非末首/末首/之前的曲/清空）/洗牌模式下删除当前曲队列一致性（T7）
- 文件名解析与时间格式化

> 测试曾暴露一个真实缺陷：洗牌模式下删除当前曲后新当前曲未对齐洗牌队列，导致后续出现重复曲目——已修复并回归通过。

## 操作说明

| 操作 | 方式 |
|---|---|
| 导入音乐 | 底部「导入」按钮多选，或直接把音频文件（可带同名 .lrc）拖进页面 |
| 播放/暂停 | 空格 / 底部播放键 / 点击列表歌曲 |
| 切歌 | N / P 键 / 上一首下一首按钮 / 点击列表项 |
| 快进快退 | ← / → 键（±5s）/ 进度条点击或拖拽 |
| 音量 | ↑ / ↓ 键 / 音量滑条 / 喇叭图标静音 |
| 播放模式 | 模式按钮循环切换（顺序 → 列表循环 → 单曲循环 → 随机） |
| 删除歌曲 | 列表项悬停出现的垃圾桶图标；「清空」按钮清空全部 |

## 版权与音源说明

本项目**不内置任何在线曲库**，仅播放用户自行导入的本地文件。请确保所播放内容拥有合法授权，音源使用责任由使用者自行承担。

## 已知限制

- 暂未解析音频内嵌 ID3 封面（封面为旋转唱片占位）；如需可后续接入 jsmediatags
- flac/opus 等格式能否播放取决于浏览器解码能力（Safari 对 flac 支持有限），播放失败会自动跳过并提示
- IndexedDB 被禁用（如部分隐私模式）时，本地歌曲仅本次会话有效，刷新需重新导入
